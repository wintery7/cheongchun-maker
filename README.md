# 청춘을 만들어가자

의자 하나로 10분. 부모님 체력이 동년배 100명 중 몇 번째인지, 기록이 비슷한 어르신들이
국민체력100에서 실제로 어떤 운동처방을 받았는지 알려주는 모바일 웹 서비스입니다.

- 서비스 URL: https://wintery7.github.io/cheongchun-maker/
- 운영주체: 김민재, 이세림
- 구조: 정적 웹 한 파일(`index.html`) + 사전 가공 데이터. 서버·로그인·외부 API 없음.
  입력값은 브라우저 안에서만 계산되며 전송·저장되지 않습니다(사용자가 '기기에 저장'을 누른 경우만 해당 기기 localStorage).

## 데이터 → 가공 → 기능

| 원천 컬럼 | 가공 | 서비스 기능 |
|---|---|---|
| `AGRDE_FLAG_NM`='어르신', `MESURE_AGE_CO`, `SEXDSTN_FLAG_CD` | 만 65~100세 추출, 5세 연령대 부여 | 비교 집단(같은 성별·연령대) |
| `MESURE_IEM_023`(의자 앉았다 일어서기), `025`(2분 제자리 걷기), `026`(3m 표적 돌아오기) | 범위 밖 값 결측 처리 후 성별×연령대 0~100 분위수 | 동년배 100명 중 순위 |
| 위 3항목 + 나이 | 성별×만나이 중앙값(±2세 창) → 등위회귀로 단조 보정 | 체력나이(항목별·종합) |
| 위 3항목 + 나이 + 인증등급(`CRTFC_FLAG_NM`, 항목별 데이터는 `COAW_FLAG_NM`) | 6등급 체계 시행(2025.6.2) 이후 40,573건, 표준화 거리로 이웃 100명, 등급 중앙값 | 예상 인증등급(홀드아웃 4,057건 ±1등급 91.2%, 찍기 76.1%) |
| `MVM_PRSCRPTN_CN`(운동처방 내용) | 준비/본/정리 구간 분해, 302개 운동명 사전, 장소 분류(집/소도구/체육시설/수영장) | 비슷한 어르신 100명 중 처방받은 인원, 같은 성별 전체 처방 비율과 비교 |
| `CNTER_NM` | 센터명 → 시도·시군구 수작업 매핑, 어르신 측정 건수 집계 | 우리 지역 국민체력100 센터 |
| 체육시설 `FCLTY_FLAG_NM`='공공', `FCLTY_STATE_VALUE`='정상운영', `DEL_AT`='N', `FCLTY_TY_NM`, `FCLTY_LA/LO` | 생활체육관·수영장·간이운동장 추출, 좌표 소수 4자리 | 처방 운동 장소에 맞춘 동네 시설 안내 |

상세 규칙과 처리 건수는 `scripts/preprocess.py` 주석과 `data/meta.json`에 있습니다.

### 데이터 품질 점검
측정항목 컬럼은 문화빅데이터플랫폼 컬럼 정의서 기준으로 사용했고, 원본에서 다음을 점검·처리했습니다(`data/meta.json`).
- 데이터 결합: 항목별 데이터(2022.1~2026.4) + 종합 데이터(2026.5~7) = 전 연령 1,383,612건, 어르신 147,928건
- 겹친 기간: 2026.5~7 항목별 어르신 기록의 99.9%가 종합 데이터와 일치 → 이중 집계를 막기 위해 이 기간은 종합 데이터만 사용
- 중복 파일: 항목별 `202210` 파일이 `202309` 파일과 바이트 단위로 동일(2022년 10월분 없음) → 한 번만 사용
- 부분 파일: 항목별 `202603`(1일치), `202607`(3일치)
- 인증등급 체계: 2025.6 이전 1~3등급+참가, 이후 1~6등급 → 예상 등급은 2025.6.2 이후 기록만 사용
- `026`(의자에 앉아 3m 표적 돌아오기) 단위: 정의서는 '회'이나 값의 96.6%가 소수점(중앙값 5.5)이라 초 단위로 처리
- 0회 기록: 의자 일어서기 1,192건, 2분 제자리 걷기 652건 → 측정 불가·미측정으로 보고 제외
- 3m 표적 돌아오기 30초 초과 139건(최대 508초) → 입력 오류로 보고 제외
- 100세 초과 18건 제외(만 65~100세만 사용)
- 체육시설: 시험 입력으로 보이는 시설 1건, 폐업·삭제 시설 제외
- 예상 인증등급: 홀드아웃 4,057건 정확히 45.5%(한 등급만 찍기 25.9%), ±1등급 이내 91.2%(찍기 76.1%)

## 다시 만들기

```bash
pip install pandas numpy scikit-learn
python3 scripts/preprocess.py --raw raw --out data   # data/*.json 생성, 처리 요약 출력
python3 scripts/build.py                              # data를 넣어 index.html 생성
python3 scripts/effects.py --raw raw --data data     # 기대효과 수치 재현 → data/effects.json
```

## 사용한 외부 자원과 라이선스

- 글꼴: Hahmlet, IBM Plex Sans KR (Google Fonts, SIL Open Font License 1.1). 그 외 외부 라이브러리 없음(순수 HTML/CSS/JS).
- 아이콘·점 그래픽: 직접 작성한 인라인 SVG.
- 지도 보기: 카카오맵 공개 링크(`map.kakao.com/link/map/이름,위도,경도`)로 이동만 함(지도 API·키 사용 없음).
- 운동 이름: 원천 데이터의 처방 문구를 그대로 표기.
- `data/knn.json`은 원천 레코드에서 회원ID·센터·측정일을 뺀 축약본(나이·3항목·등급·처방 ID)입니다. 데이터 이용허락 조건상 재배포 가능 여부: [확인 필요]
